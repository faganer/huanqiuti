| 项目 | 内容 |
| :--- | :--- |
| 计费方式 | 月付（含季付 / 半年 / 年付）、一次性流量包 |
| 起步价格 | 月付 ¥15 起，一次性包 ¥39 起 |
| 流量规则 | 月付套餐流量每月重置；流量包不按月清零 |
| 客户端平台 | iOS、Android、Windows、macOS |
